The Homebrew Catalog documentation/source was inspected at commit `2f5ba3627fe4c9bfe645dcb16e907b771c89297a`. Its older feed is explicitly still supported and contains full app records in one request; that makes it suitable for this small allowlist. Atlas uses HTTPS and cross-checks selected file digests against GitHub metadata; it does not claim to verify the newer API's signed manifest. Downloaded binaries, runtime behavior and firmware compatibility were not tested.

A further expansion can review additional original homebrew games and tools from this catalog, then extend the allowlist, or configure another developer's published release pattern. Ports requiring separately owned game data need accurate descriptions and a publisher statement that their release excludes that data before approval. This audit did not approve such ports as full commercial games.

## Expansion review

The three added developer sources were checked against their public release metadata on 2026-10-21. ScreenTester5 and SymphonyStation5 release tags resolve to the same commits linked above. VITA5 release tag `v1.0.0` resolves to `d1189346aab5d88c89ba7e4bf0277ed06000478f`; the pinned later README documents the project's GPL grant and app scope. Each matching asset has a publisher SHA-256 and passed live metadata verification. No binary was fetched or inspected, and no firmware/runtime guarantee is inferred from these documents.

The refreshed homebrew feed identified source commit `91a1963e884ee65f4b099227bb7eaa386fa227fa`. Its original three-repository allowlist remains unchanged; the other 100 records were filtered in the verified build. Future releases of approved developers refresh within the configured filename scope, but changes to distribution rights still require review. None of the unreviewed feed entries or legacy commercial indices was bulk-enabled.

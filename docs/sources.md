# Public source research — 2026-10-21

Only primary publisher/project documentation was used. Public access and metadata licensing do not by themselves establish permission to distribute commercial game assets. Atlas does not bypass login, payment, verification or access controls.

The Homebrew Catalog documentation/source was inspected at commit `2f5ba3627fe4c9bfe645dcb16e907b771c89297a`. Its older feed is explicitly still supported and contains full app records in one request; that makes it suitable for this small allowlist. Atlas uses HTTPS and cross-checks selected file digests against GitHub metadata; it does not claim to verify the newer API's signed manifest. Downloaded binaries, runtime behavior and firmware compatibility were not tested.

A further expansion can review additional original homebrew games and tools from this catalog, then extend the allowlist, or configure another developer's published release pattern. Ports requiring separately owned game data need accurate descriptions and a publisher statement that their release excludes that data before approval. This audit did not approve such ports as full commercial games.
